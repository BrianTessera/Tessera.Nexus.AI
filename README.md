# Tessera Nexus AI

Tessera Nexus AI is an internally hosted, local-LLM-powered analytics platform for Epicor Kinetic.

## Sprint 1 Goal

Create the foundational solution, project structure, and database-ready architecture for:

- Epicor metadata cache
- Business knowledge repository
- Security policy layer
- Audit logging
- Future local LLM SQL generation

## Target Framework

.NET 10

- Tessera.Nexus.AI.Web
- Tessera.Nexus.AI.Domain

- Tessera.Nexus.AI.Metadata
